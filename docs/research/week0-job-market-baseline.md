# WEEK 0 채용 표본 기준선

## 목적과 범위

WEEK 0의 직무 탐색기는 학생에게 "보안 직무"라는 넓은 말을 실제 업무와 산출물로 나누어 보여주기 위한 교육용 보기다. 이 문서는 배포 데이터의 해석 범위를 고정한다.

- 표본: 실제 공개 채용공고 21건을 정리한 1차 표본
- 구성: 국내 10건, 국외 11건
- 정보 밀도: 상세 Seed 13건, Partial Seed 8건
- 별도 기록: 제목과 URL만 제공된 싸이버원 침해사고 조사 담당자 공고 1건
- 비목적: 전체 채용시장의 통계, 채용 수요 순위, 현재 모집 여부 판단

이 표본에서 보이는 빈도는 채용시장 전체의 비율이 아니다. 표본에 없는 역할이 덜 중요하다는 뜻도 아니다.

## 분야별 역할 지도 보강

`deep-research-report (1).md`의 심층 리서치를 별도 계층으로 반영했다. 이 계층은 16개 전문 분야와 분야별 대표 역할 113개를 제공한다. 역할 수는 채용 수요 순위가 아니라 학생이 분야 안의 역할 분화를 파악하기 위한 대표 목록이다.

- 상세 근거 카드: 공고 직접 확인·공식 직무 체계·공식·산업 자료 중 근거 상태가 남아 있는 33개 역할
- 대표 역할 목록: 보고서가 제시한 분야별 역할 목록. 개별 공고 URL이나 원문이 보존되지 않은 경우 외부 링크와 현재 모집 상태를 표시하지 않음
- 추가 표본 필요 역할: API Security, Kubernetes Security, OT IR 등은 독립 공고 표본이 부족하다는 보고서의 분류를 유지하며 기본 관계도에서 독립 노드로 만들지 않음

## 사용 원칙

1. 직무명만으로 실제 책임을 단정하지 않는다.
2. 공고 본문에 적힌 사실과 SecTrack의 정규화 분류를 구분한다.
3. 산출물은 공고 업무 문장에서 도출한 경우 `본문 기반 추론`으로 표시한다.
4. 특정 직무의 일반적인 설명은 공고 사실처럼 표시하지 않는다.
5. 모집 상태·URL·날짜가 없는 공고는 "현재 상태 미확인"으로 유지한다.
