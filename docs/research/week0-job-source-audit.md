# WEEK 0 공고 출처 감사표

## 데이터 경계

이 표는 handoff에 보존된 공고 이름과 본문 요약을 앱 데이터로 옮긴 결과다. 개별 공고의 공개 URL, 지원 URL, 게시일, 마감일, 현재 모집 여부는 handoff에 없으면 `null`로 유지했다. 따라서 아래 21건은 현재 채용 중이라는 의미가 아니다.

`상세 Seed`는 업무·요건 등 복수 필드가 handoff에 보존된 항목이고, `Partial Seed`는 일부 업무 키워드와 역할 연결만 보존된 항목이다. Partial Seed의 빈 필드는 추정하지 않는다.
