# WEEK 0 개편 요약

## 바뀐 학습 구조

WEEK 0은 `정보보안 핵심 용어와 분야·직무 지도`로 교체했다.

1. 이번 주: 용어·분야·직무·공고 근거를 구분하는 학습 순서
2. 보안 용어: 30개 용어, 쉬운 설명, 정확한 설명, 예시, 흔한 오해, 비교 용어, CWE·CVE·CVSS 흐름
3. 분야·직무 지도: 운영자가 정한 16개 전문 분야, 113개 대표 역할, 상세 근거 카드 33개를 분야 → 직무군 → 세부 직무 구조로 보기
4. 나의 보안 지도: 관심 분야·직무·산출물 후보를 선택하고 JSON 내보내기
5. 이해 확인: WEEK 0 전용 13문항, 11문항 이상 정답 기준

## 제거 또는 비노출 처리

- WEEK 0의 이전 플랫폼 사용법·윤리·ROE·베이스라인 UI
- Concept Reader의 우측 목표·메모·관련 흐름 레일
- 짧은 확인, 자기 설명, 숙련도·자신감·복습 입력 UI
- 모든 사용자 화면의 예상 시간/분 단위 표시

이전 모듈과 실습 ID는 활성 UI에서 제거했지만, 기존 `localStorage`의 값을 삭제하거나 덮어쓰지 않는다.

## 데이터와 검증

- 16개 전문 분야와 운영자가 제공한 총 113개 역할 목록
- 공고 직접 확인·공식 직무 체계·공식·산업 자료로 분류한 상세 근거 카드 33개
- 기존 21개 공고 표본과 별도 metadata-only 기록 1건은 보존
- 대표 역할은 채용 수요 순위가 아니며, 공개 URL이 보존되지 않은 인용은 링크·현재 상태를 만들지 않음
- 직급·Tier 분리와 전역 중복을 막고, 역할별 주 소속·연결 분야·제품 개발 맥락을 분리
- 단위 테스트로 분야별 대표 역할 수, 직무군 배정, 연결 분야, Tier 정규화를 검증하고, Playwright로 하나의 관계도 캔버스에서 `분야 → 직무군 → 역할` 노드 확장을 검증
