# STEP 2 제품 문구 변경

제품 모드는 `local-personal`이다. 서버 검토나 다중 사용자 기능처럼 보이던 문구를 다음처럼 바꿨다.

| 이전 | 변경 |
|---|---|
| TODAY | 다음 할 일 |
| 최근 피드백·운영자 시각 | 현재 활동에 대한 자동 학습 안내 |
| 김보안·학습자/운영자 | 내 학습·이 브라우저에만 저장 |
| 운영자 | 내 학습 분석 |
| 주차 제출 | 주차 학습 정리 |
| 미제출 | 정리하지 않은 주차 |
| 증거 제출 | 주차 학습 정리 |
| 검토 요청 | 작성 완료 |
| 검토됨 sample | 읽기 전용 sample |
| 자동 저장 중 | 이 브라우저에 자동 저장 |

`증거`는 무조건 치환하지 않았다. XSS Finding, 요청·응답, 재시험, 포렌식·감사처럼 전문 의미가 정확한 위치에는 유지한다. 일반 내부 실습의 공통 패널 명칭은 STEP 4에서 activity type별로 분리한다.

출처 없는 `2025 KISIA 채용 공고 세부 직무 사례` 수치 차트와 사용되지 않던 가상 멤버·점수 데이터 `src/data.js`는 제거했다. 기존 세 장은 개별 진행 중 공고가 아니라 2026 KISIA 취업박람회 참가기업 프로필 자료임을 화면에서 명시했다.
