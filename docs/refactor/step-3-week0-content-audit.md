# STEP 3 Week 0 콘텐츠 감사

## 정보 구조

- canonical 화면: `#/mindmap`
- 호환 진입: `#/labs/w0-map`은 generic lab shell 없이 같은 화면으로 연결
- 기본 제목: `나의 보안 직무 지도`
- 보기: 직무로 보기, 역량 연결 보기, 개념으로 보기
- canonical 노드 유형: `jobFamily`, `role`, `concept`, `technology`, `standard`, `threat`, `control`, `industry`
- 직무군 12개, 세부 직무 12개

## 상세 패널

- 직무군: 대표 직무, 자산, 협업 관계, 학습 영역
- 직무: 실제 업무, 프로젝트, 기초·역량·도구·표준, 산출물, 협업, 신입 기대, 4단계 학습 순서, 포트폴리오, 주차, 출처
- 개념·기술·표준·산업: 각 유형에 맞는 중립 설명
- 위협: 성립 조건과 공격 흐름을 포함
- 통제: 보호 대상, 적용 위치, 원리, 운영, 한계, 확인 방법을 포함
- 직무와 중립 개념에는 공격·방어 공통 카드를 표시하지 않는다.
- 알 수 없는 개인 노드에도 공격·방어 내용을 임의 생성하지 않는다.

## 조작과 저장

- 첫 진입 시 상세 패널은 닫혀 있고 지도가 전체 너비를 사용한다.
- 패널 닫기, 루트 compact/expanded, 확대·축소, 전체 맞춤, 선택 중심, 전체 화면을 제공한다.
- 검색 결과는 강조하며 결과 선택 시 해당 보기로 이동한다.
- 보기 모드, 선택 노드, 루트 상태, 그룹 펼침, 확대율, 관심 직무, 개념 숙련도, 확신도, 복습 상태, 메모를 저장한다.
- 지도 JSON은 512KB, 사용자 노드 50개, 문자열 길이, 허용 상태와 노드 ID를 검증한다.

## 실제 브라우저 확인

- 노드 미선택 상세 패널 수 0.
- 직무 패널에 실제 수행 업무와 학습 순서가 있고 공격 관점이 없음을 확인.
- 개념 패널에 정의가 있고 공격 흐름이 없음을 확인.
- XSS 위협 패널에서만 성립 조건과 공격 흐름을 확인.
- 관심 직무와 메모가 새로고침 후 보존됨.
- 150% 글자 크기에서 root font 24px, 문서 가로 overflow 0.
- 390x844에서 문서 가로 overflow 0. 지도 자체는 내부 canvas에서 스크롤한다.
- uncaught page error와 console error 0.
