# STEP 1 제품 모드

## 확정 모드

`local-personal`

현재 저장소에는 백엔드, 사용자 계정, 권한 모델, 제출 API, 리뷰 API, 분석 수집 API가 없다. 모든 학습 데이터는 한 브라우저의 localStorage에만 저장된다. 따라서 이 앱이 사실대로 제공할 수 있는 것은 개인의 읽기 기록, 실습 상태, 퀴즈 결과, 메모, 보고서 초안, 지도 관심 상태와 이 데이터에서 계산한 개인 분석이다.

## 표시 데이터 분류

| 항목 | 현재 분류 | 근거와 조치 |
|---|---|---|
| 사용자 이름 `김보안`과 역할 | 고정 예시 데이터 | `App.jsx`에 하드코딩. STEP 2에서 제거 |
| 현재 과정 `Week 04 · XSS` | 고정 예시 데이터 | 진도와 무관하게 고정. 다음 할 일에서 계산하도록 변경 |
| 최근 피드백과 작성 시각 | 실제처럼 보이지만 현재 구현 불가 | 피드백 저장소가 없음. 제거 또는 명확한 학습 안내로 변경 |
| 검토 요청·제출 상태 | 실제처럼 보이지만 현재 구현 불가 | 서버 워크플로가 없음. 로컬 `작성 완료`로 변경 |
| Reviewed·Fixed 상태 | 실제처럼 보이지만 현재 구현 불가 | 개인 초안 상태로 재정의 |
| 주차·실습·퀴즈 진행 | 실제 로컬 데이터에서 계산 | localStorage에서 계산되며 유지 |
| 힌트 집계 | 실제 로컬 데이터에서 계산 | 개인 학습 신호로만 사용 |
| 보고서 누락 집계 | 실제 로컬 초안에서 계산 | 개인 품질 검사로 명칭 변경 |
| 많이 막힌 개념 | 일부 임의 상수를 포함 | `+2`, `3`, `4`가 섞여 있음. 실제 이벤트만 계산하도록 변경 |
| 학습자별 통계 | 현재 구현 불가 | 다중 사용자 데이터가 없으므로 만들지 않음 |
| 채용 공고 캡처 | 공식 박람회 참가기업 프로필 캡처 | 개별 진행 중 채용 공고로 단정하지 않고 출처·확인일·상태를 표시 |
| KISIA 직무 건수 차트 | 출처를 추적할 수 없는 고정 값 | 검증 전까지 제거 |

## 데이터 경계

STEP 2부터 다음 adapter 경계를 둔다.

- storage adapter: 로컬 데이터 읽기, 쓰기, 내보내기, 가져오기, 마이그레이션
- feedback adapter: local-personal에서는 사용자 메모와 자동 학습 안내만 제공
- analytics adapter: 현재 브라우저의 실제 이벤트에서만 개인 분석 계산
서버 기능은 adapter 뒤에 추가할 수 있지만, 서버가 생기기 전까지 사용자·리뷰·알림·다중 사용자 순위는 노출하지 않는다.
